# Lab-Grade Webcam Gaze Tracking System

Hi, I'm Hüma. As a biomedical engineering student, I am highly interested in clinical signal processing and computer vision. I created this project to develop a highly stable, real-time eye-tracking system using only a standard webcam.

The goal here is simple: take raw, noisy webcam frames, process both eyes simultaneously to handle parallax, map the gaze using a lightweight neural network, and filter out the micro-jitters—achieving lab-grade spatial accuracy without expensive hardware.

### How It Works

The project relies on a combination of deep learning and robust signal processing to estimate and analyze gaze data:

* **Binocular Tensor Architecture:** MediaPipe extracts the bounding boxes for both eyes, which are then combined into a single (64, 64, 2) tensor. This compensates for depth and parallax differences during head tilts.


* **Lightweight CNN Model:** An end-to-end shallow convolutional neural network maps the eye tensors directly to screen coordinates, maintaining a stable 60 FPS on the CPU.


* **Dynamic Calibration & Saccade Rejection:** A 3-second dwell time lock ensures data is only recorded when the target is stationary. This eliminates blurry saccade frames and label noise from the training set.


* **Temporal Smoothing:** An adaptive Kalman filter is applied to the CNN output. It suppresses tracking jitters and outliers without introducing phase lag during dynamic tracking scenarios.


* **Latency Compensation & DTW Analysis:** During the post-processing phase, Dynamic Time Warping (DTW) and phase lag compensation are used to evaluate the true geometric trajectory accuracy, isolating the system's inherent latency from spatial error.



### Project Files

* `main.py`: The core real-time tracker script. It handles the Pygame UI, MediaPipe face mesh extraction, dynamic calibration, live CNN training, and the interactive testing phase.


* `gaze_analysis.py`: The post-processing script. It cleans artifacts (blinks, UI freezes), calculates RMSE/DTW metrics, and generates deterministic heatmaps, trajectory plots, and error distribution graphs.


* `requirements.txt`: Contains all necessary Python dependencies (Pygame, OpenCV, MediaPipe, TensorFlow, fastdtw, etc.).


* `lab_gaze_tracking_data.csv`: The default output dataset generated by the system for testing the analysis pipeline.



### Usage

To test the system on your machine:

1. Clone this repository.
2. Install the required libraries by running `pip install -r requirements.txt` in your terminal.


3. Run `python main.py`. Look at the yellow targets during the calibration phase and press ENTER to start. Once 50+ frames of calibration data are collected, the CNN will automatically train itself and transition to the dynamic tracking test.


4. After the session, the system will save your tracking data to `lab_gaze_tracking_data.csv`.


5. Run `python gaze_analysis.py` to analyze your results. This will process the raw data, calculate the optimal phase shift, and save the validation plots and a summary JSON report to the `runs/` folder.
