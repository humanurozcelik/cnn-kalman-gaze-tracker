# Webcam Gaze Tracking with CNN + Kalman Filtering

A webcam-based gaze-tracking prototype that combines MediaPipe eye localization, binocular eye crops, a shallow convolutional neural network, and Kalman filtering to estimate gaze position on screen.

The project was developed as a biomedical engineering/computer-vision study and is intended for experimentation, portfolio demonstration, and method development rather than clinical use.

## What the Project Does

The real-time pipeline:

1. Captures webcam frames with OpenCV.
2. Uses MediaPipe Face Mesh to locate facial and eye landmarks.
3. Extracts normalized left- and right-eye crops.
4. Combines the two eye images into a `64 x 64 x 2` binocular tensor.
5. Collects calibration samples from a 9-point screen grid.
6. Trains a lightweight CNN to map eye appearance to screen coordinates.
7. Applies a 2D constant-velocity Kalman filter to smooth the predicted gaze trajectory.
8. Logs target position, gaze estimate, EAR, tracking status, frame age, and screen dimensions to CSV.

The post-processing script then performs artifact screening, spatial-error analysis, post-hoc temporal alignment, drift estimation, and visualization.

## Project Structure

```text
cnn-kalman-gaze-tracker/
├── main.py
├── gaze_analysis.py
├── requirements.txt
├── README.md
└── .gitignore
```

### `main.py`

Runs the webcam tracker and calibration/test workflow.

Key components:
- MediaPipe Face Mesh landmark extraction
- Binocular grayscale eye tensor generation
- 9-point calibration
- Shallow CNN regression to screen coordinates
- Eye-aspect-ratio (EAR) based blink/low-eye-opening screening
- Kalman filtering
- CSV logging
- Fullscreen or windowed UI

### `gaze_analysis.py`

Analyzes the CSV generated by `main.py`.

Outputs include:
- raw and temporally aligned spatial error
- mean, median, RMSE, and p95 error
- artifact labels
- linear drift estimate
- trajectory plot
- spatial-density visualization
- error-over-time plot
- error distribution
- `summary.json`
- `cleaned_data.csv`

Dynamic Time Warping is supported when the optional `fastdtw` package is installed.

## Environment

Tested on Windows with **Python 3.11.9**.

Create a virtual environment:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Windows / MediaPipe path note

On some Windows setups, MediaPipe may fail to load its internal model resources when the virtual-environment path contains non-ASCII characters. If a `face_landmark_front_cpu.binarypb` error appears even though the file exists, place the project and virtual environment in an ASCII-only path such as:

```text
D:\dev\cnn-kalman-gaze-tracker
```

## Running the Tracker

For the default fullscreen interface:

```powershell
python main.py
```

For easier testing in a window:

```powershell
python main.py --windowed
```

To display a small webcam preview during calibration:

```powershell
python main.py --windowed --preview
```

Press **ENTER** to start calibration and follow the target with your eyes. After calibration, the CNN is trained on the collected samples and the dynamic tracking phase begins.

The default session output is:

```text
lab_gaze_tracking_data.csv
```

## Analyzing a Session

After completing a tracking session:

```powershell
python gaze_analysis.py --csv lab_gaze_tracking_data.csv
```

Analysis outputs are written to a timestamped directory under:

```text
runs/
```

## Methodological Notes

- The CNN is trained per calibration session rather than distributed as a pretrained gaze-estimation model.
- The Kalman filter smooths the coordinate estimates; it does not correct systematic calibration bias.
- The temporal-alignment step in `gaze_analysis.py` is a **post-hoc frame-shift optimization** and should not be interpreted as a direct measurement of end-to-end system latency.
- Accuracy depends on camera placement, lighting, head pose, calibration quality, screen geometry, and user behavior.
- The current implementation is an experimental prototype and has not been validated as a clinical or laboratory eye tracker.
